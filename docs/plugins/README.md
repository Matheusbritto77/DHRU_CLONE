## 🚀 Início Rápido

1. Acesse `seusite.com/admin`
2. Faça login com sua conta de administrador
3. No menu lateral, vá em **"Construtor de Páginas"**
4. Comece editando a **"Página Inicial"** para se familiarizar

---

## ⚡ Resumo de Ações

| Eu quero... | Onde ir |
|---|---|
| Mudar textos e cores da página inicial | Páginas do Site → Editar "Página Inicial" → Configurações dos blocos |
| Trocar as imagens do carrossel | Personalização (menu lateral) → Aba "Banners" |
| Trocar a logo | Personalização → Aba "Identidade do Site" |
| Adicionar uma nova seção | Plugins → Novo Plugin → Depois adicionar na página |
| Criar uma página nova | Páginas do Site → Nova Página |
| Esconder uma seção temporariamente | Editar página → Desativar "Visível" no bloco |
