# 🧩 Sistema de Plugins — Introdução

## O que são Plugins?

Plugins são **blocos visuais reutilizáveis** que compõem as páginas do seu site. Cada pedaço que você vê na sua página inicial — a barra de contatos no topo, o menu de navegação, o carrossel de imagens, os cartões de serviços e o rodapé — **é um plugin independente**.

Pense neles como peças de LEGO: cada peça tem sua forma e função, e você decide como montá-las.

---

## Por que usar Plugins?

| Benefício | Descrição |
|---|---|
| **Sem tocar em código** | Você edita textos, cores e imagens direto pelo painel Admin, sem precisar abrir nenhum arquivo. |
| **Reordenação fácil** | Quer que o carrossel apareça depois do texto? Basta arrastar o bloco para outra posição. |
| **Segurança** | Plugins do sistema (como a Navbar) são protegidos, não podem ser deletados acidentalmente. |
| **Expansível** | Novos plugins podem ser criados a qualquer momento para adicionar funcionalidades ao site. |

---

## Conceitos Importantes

### 📄 Página
Uma **Página** é uma URL do seu site (ex: a página inicial `/`). Cada página é formada por um conjunto de plugins empilhados de cima para baixo.

### 🧩 Plugin
Um **Plugin** é um componente visual (ex: "Barra de Navegação", "Rodapé", "Carrossel de Banners"). Ele contém o visual (HTML) e as opções que você pode personalizar (texto, cores, imagens).

### 📦 Bloco
Um **Bloco** é quando você coloca um Plugin dentro de uma Página. É a conexão entre os dois. Cada bloco pode ter suas próprias configurações personalizadas.

## Plugins Padrão Incluídos

O sistema já vem com **6 plugins pré-instalados** que formam a sua página inicial:

| # | Plugin | O que faz |
|---|---|---|
| 1 | **Barra Superior (Contatos)** | Mostra e-mail e WhatsApp de suporte no topo. |
| 2 | **Barra de Navegação** | Menu com logo, botão de Login e Registrar. |
| 3 | **Carrossel de Banners** | Imagens promocionais que giram automaticamente. |
| 4 | **Texto Principal (Hero)** | Título chamativo, subtítulo e botões de ação. |
| 5 | **Cartões de Funcionalidades** | Grade com 3 cards destacando diferenciais. |
| 6 | **Rodapé do Site** | Logo, redes sociais, contatos e copyright. |

> ⚠️ Esses plugins são marcados como **"Core"** (protegidos). Você pode editá-los à vontade, mas não pode excluí-los.
